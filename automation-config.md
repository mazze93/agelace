## TASK 1: WEEKLY WORLDBUILDING EXPANSION

### Task Configuration

**Name:** Weekly Worldbuilding Deep Dive  
**Frequency:** Weekly | Sunday | 9:00 AM  
**Space:** WORLDBUILDING CORE  
**Model:** Claude 4.0 Sonnet  
**Search Mode:** Internal Knowledge (uploaded files only)  
**Notification:** Email + In-app

### Task Prompt (Copy Entire Block)

```
WEEKLY WORLDBUILDING DEEP DIVE - [PROJECT NAME]

---CONTEXT FROM WORLD FILES---
[Your worldbuilding document will be automatically loaded from Space files]

---THIS WEEK'S DEVELOPMENT---

You are a worldbuilding specialist. Analyze the current world state and develop THREE underdeveloped elements in depth.

ELEMENT SELECTION:
Choose 3 of these (or substitute your own based on priority):
- Magic system: [aspect that hasn't been deeply explored]
- Culture/Society: [aspect that needs development]
- History/Lore: [aspect that could deepen implications]
- Conflict: [system tension not fully mapped]
- Geography/Resources: [environmental consequences unexplored]

FOR EACH ELEMENT:

**[ELEMENT NAME]**

CURRENT STATE:
- What's established about this element?
- What are the CORE RULES/CONSTRAINTS?

IMPLICATION MAPPING (5 implications):
- If [constraint is true], then [implication 1 must follow]
- If [constraint is true], then [implication 2 must follow]
- Continue for 5 total

EXPANSION VECTORS (2-3 directions):
- Direction 1: [How to deepen this element]
- Direction 2: [Alternative exploration]
- Direction 3: [Provocative possibility]

CONSISTENCY CROSS-CHECK:
- Does this align with established lore? ✓ or ⚠️ Flag conflicts
- Does this affect other world systems? (economics, politics, magic, culture)
- Any retcon needed? (changes to existing lore)

STORY APPLICATION:
- How does this affect [CHARACTER 1]'s understanding/choices?
- What CONFLICT emerges from this?
- What SCENE would showcase this development?

---OUTPUT FORMAT---

For each of 3 elements, provide:

## [ELEMENT NAME]

**Current Constraint:** [The limiting rule or fact]

**5 Implications:**
1. [If this, then this...]
2. [If this, then this...]
3. [If this, then this...]
4. [If this, then this...]
5. [If this, then this...]

**Expansion Vectors:**
- → [Direction 1: expansion approach]
- → [Direction 2: expansion approach]
- → [Direction 3: expansion approach]

**Consistency Check:** [Any flags or alignment notes]

**Story Integration:** [How this matters to your characters/plot]

---

SYNTHESIS:

After all 3 elements, provide:

**Cross-Element Connection:**
Show ONE way these 3 elements connect or interact that hasn't been explored yet.

**New Complications:**
List 1-2 conflicts/complications that emerge from this week's worldbuilding.

**Questions for Author:**
3 open questions to deepen this further:
1. [Question]
2. [Question]
3. [Question]

**Next Week's Recommendations:**
Which element should develop next for maximum story impact?

---TONE & APPROACH---
Systematic. Building outward from constraints, never inventing exceptions.
Assume author's world has internal logic—help extend it, don't contradict it.
Flag gaps for author to decide how to resolve them.
```

### How to Integrate Results

1. **Review Sunday morning** (task notifies you)
2. **Pick 1-2 expansion vectors** that align with your story needs
3. **Add to world bible** within 24 hours (while fresh)
4. **Check consistency** against character actions/plot
5. **Archive weekly notes** in project folder for pattern recognition

## TASK 3: PLOT PACING REVIEW

### Task Configuration

**Name:** Bi-Weekly Plot & Pacing Review  
**Frequency:** Every other Friday | 7:00 PM  
**Space:** PLOT ARCHITECTURE  
**Model:** Kimi K2 Thinking  
**Search Mode:** Internal Knowledge (uploaded files only)  
**Notification:** Email + In-app  
**Week Pattern:** Runs on weeks 2, 4, 6, 8 of month

### Task Prompt (Copy Entire Block)

```
BI-WEEKLY PLOT ARCHITECTURE & PACING REVIEW - [PROJECT NAME]

---CURRENT OUTLINE---
[Your outline from Space will load automatically]

---SCENES WRITTEN SINCE LAST REVIEW---
[Most recent scenes written since last pacing review]

---ANALYSIS---

You are analyzing the structural soundness and pacing of the story in its current state.

## SECTION ASSESSMENT

Current story section covers: [SCENES X-Y / DESCRIPTION]

**DRAMATIC TENSION TRAJECTORY:**

Map the tension curve:
- Opening: [How high is tension/stakes at start?]
- Early rise: [How quickly does tension build?]
- Midpoint: [Where's the emotional center of this section?]
- Complications: [What raises stakes?]
- Climax: [What's the highest intensity moment?]
- Resolution: [How does tension resolve?]

Visual assessment (use this format):
```
Tension Curve:
       [High]     /\
             |    /  \
       [Med] |   /    \___
             |  /
       [Low] |_/__________|
              Start    End
```

**PACING ANALYSIS:**

Scene-by-scene breakdown:

| Scene | Function | Pace | Duration? |
|-------|----------|------|-----------|
| [Scene X] | [Plot/char/emotion] | Fast/Medium/Slow | Too short/Right/Too long? |
| [Scene Y] | [Plot/char/emotion] | Fast/Medium/Slow | Too short/Right/Too long? |

Findings:
- Fastest section: [Where does pacing accelerate?]
- Slowest section: [Where does it bog down?]
- Breathing room: [Where do readers get to absorb?]
- Rushes: [What happens too fast?]

**WORK DISTRIBUTION:**

Which scenes are doing MULTIPLE types of work (efficient storytelling)?
- Scene X does: [Plot + Character + Emotion] = HIGH EFFICIENCY
- Scene Y does: [Plot only] = NEEDS WORK

Which scenes could be COMBINED or CUT?
- Scenes A & B both do [X function]—combine into one scene?
- Scene C does only [X]—cut or integrate elsewhere?

**CHARACTER ARC IN THIS SECTION:**

[PRIMARY CHARACTER] emotional journey:
- Start: [State at beginning]
- Turn 1: [First shift/realization]
- Turn 2: [Second shift/complication]
- Turn 3: [Third shift/decision]
- End: [Final state]

Is this arc EARNED? (Do the turns flow from character choices + events?)
YES / PARTIALLY / NO → [Explanation]

What SCENE marks each turn?

**TURNING POINTS:**

Identify every moment where character understanding/agency CHANGES:

| Turning Point | Scene | What Changes? | Is It Earned? |
|---------------|-------|---------------|---------------|
| [TP 1] | [Scene X] | [What character now knows/wants/can do] | YES/NO |
| [TP 2] | [Scene Y] | [What character now knows/wants/can do] | YES/NO |

If any are not earned, what needs to happen first to make them earned?

**PLOT LOGIC CHECK:**

- Do character actions make sense given what they know?
- Are mysteries/secrets protected adequately? (readers don't figure it out too early?)
- Do consequences flow from character choices?
- Any logic gaps? (things that don't connect or contradict)

**BETA READER LENS:**

If a beta reader were reading this section for the first time:
- What would confuse them?
- What would feel rushed?
- What would feel slow?
- What emotional beats would hit?

---OUTPUT---

## [SECTION NAME] - PACING REPORT

**Dramatic Structure: STRONG / NEEDS WORK / REBUILD**

**Pacing Assessment:**

✓ [What's working well]
✗ [What needs attention]

Issues (Priority order):
1. [Critical issue: X] → Impact: [Why it matters] → Fix: [How to address]
2. [Important issue: Y] → Impact: [Why it matters] → Fix: [How to address]
3. [Polish issue: Z] → Impact: [Why it matters] → Fix: [How to address]

**Character Arc Status:**
[Character]'s arc in this section: ON TRACK / NEEDS WORK

Key turning points: [Scene 1], [Scene 2], [Scene 3]

**Turning Points Readiness:**
Next turning point: [TP X in Scene Y]
- Is it set up? YES / PARTIALLY / NO
- What needs to happen first: [What's required]

**Revision Priorities (Top 3):**
1. [Fix X] - Impact: High - Effort: Medium
2. [Fix Y] - Impact: Medium - Effort: Low
3. [Fix Z] - Impact: Medium - Effort: High

**Outline Adjustment Recommendation:**
[Should you redistribute scenes? Combine? Cut? Expand?]

**Go/No-Go for Next Section:**
Can you move forward? YES / NEEDS REVISION / NEEDS MAJOR WORK

**One Moment to Celebrate:**
[What's working best in this section?]
```

### How to Integrate Results

1. **Receive report bi-weekly** (Fridays every other week)
2. **Review pacing assessment immediately** while fresh
3. **Prioritize top 3 fixes** for next writing session
4. **Test outline adjustment** before next session
5. **Archive reports** to track pacing patterns across full story

## TROUBLESHOOTING

**Problem:** Task running but output feels generic
→ Solution: More specific context in prompt. Before task runs, upload most recent scenes + outline. Specific context = specific output.

**Problem:** Task timing doesn't work for me
→ Solution: Change frequency. Nothing says Task must run Sunday—run when you'll actually review it.

**Problem:** Task output too short/too long
→ Solution: Edit prompt to specify length. Add "[OUTPUT: 3-5 bullet points]" or "[OUTPUT: Full detailed analysis]" to control scope.

**Problem:** Inconsistent quality between runs
→ Solution: Upload complete context files. Incomplete context = inconsistent output.

**Problem:** Need task to run more frequently
→ Solution: Create duplicate task with modified schedule. Example: Weekly Task + Monthly Task run on same subject, different depth.
