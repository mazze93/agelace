This folder is your world.

Everything you make in agelace is saved here, as you type. Copy this folder
somewhere safe and you have backed up everything.

  entries/   your pages, one file each
  canvases/  your boards
  fonts/     drop .otf / .ttf / .woff2 files here to use them
  forge/     hands you draw in the Forge
  assets/    images you place on boards
  .trash/    things you deleted (they are never really thrown away)

You can leave this README here; agelace ignores it.
