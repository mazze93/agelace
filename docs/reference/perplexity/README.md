# Planning-session reference (Perplexity)

These files came out of the planning sessions in Perplexity, before any code
existed. They are kept as a record of where agelace started, not as a
description of what it is.

- `agelace.md` is the original brief. Its browser-storage plan was replaced
  on 2026-10-17 by a folder on the host (`./world`).
- `test-report.md` reports tests as "passing" that never ran against any
  code. Nothing in it is evidence. The real checks are Vitest, `bruno/`, and
  `e2e/`, all run by CI.
